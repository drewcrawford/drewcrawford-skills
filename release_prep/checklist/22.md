# Semver

We need to make sure our version number is correct.

Use cargo semver-checks

```bash
cargo sermver-checks
Building exfiltrate v0.1.0 (current)
   Built [  17.753s] (current)
 Parsing exfiltrate v0.1.0 (current)
  Parsed [   0.004s] (current)
Building exfiltrate v0.1.0 (baseline)
   Built [  15.567s] (baseline)
 Parsing exfiltrate v0.1.0 (baseline)
  Parsed [   0.006s] (baseline)
Checking exfiltrate v0.1.0 -> v0.1.0 (no change; assume minor)
 Checked [   0.016s] 159 checks: 153 pass, 6 fail, 0 warn, 41 skip
...
Summary semver requires new major version: 6 major and 0 minor checks failed
Finished [  34.684s] exfiltrate
```

In this example, v0.1.0 refers to TWO versions:
* current means the one in our directory
* baseline means the last release on crates.io

This means that the user has not bumped the version, so it is our job to do so.

In this case the tool tells us we need a new MAJOR version:

0.1.0 -> 0.2.0
1.0.0 -> 2.0.0

However if the checks pass we need only a new MINOR version

0.1.0 -> 0.1.1
1.0.0 -> 1.1.0

# Edits

We will edit our chosen version in Cargo.toml.

We will also edit the CHANGELOG.md file's Unreleased heading to indicate that we are releasing this version.
