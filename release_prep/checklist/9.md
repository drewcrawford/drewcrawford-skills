We want to ensure that the README.md file has the most up to date information from src/lib.rs.  

We will need to make minor adjustments for the differences between GitHub-flavored markdown and rustdoc syntax, 

* in Rust we use [] for links and in Markdown we use ``
* the logo path is different
	* in Github we can do `![logo](art/logo.png)`
	* in Rust we have to do `![logo](https://github.com/drewcrawford/reponame/raw/main/art/logo.png)`
* We can't use .mp4 on GitHub, we have to use gif
