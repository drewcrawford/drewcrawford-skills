# MSRV

First, find the rust version declarations we have already:

```bash
grep -R "rust-version =" ../logwise --include "*.toml" --exclude-dir=target
```

Temporarily remove them (delete the line).

Use the cargo msrv find command:

```bash
cargo msrv find
```

Re-add the version declarations you deleted, using the version detected by `cargo msrv find`
