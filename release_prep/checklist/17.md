# CI update

We need to update the project's ./.github/workflows/ci.yaml with the latest
template version in release_prep/templates/ci.yml.

Read both versions, we may need to combine the project-specific information with information from the generic template.

After making this change,

```bash
git status # ensure clean
git add ./.github/workflows/ci.yaml
git commit -p -m "Update CI"
git push
```

After this, use your gitea CI skill to determine if the new CI passes or fails.

If it fails, investigate the reason, but do not fix the failure, instead report an error in this step.
