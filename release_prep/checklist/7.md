# Rust edition

We want to ensure all our Cargo.toml files use edition >=2024 and not some other version:

```bash
grep -R --include="*.toml" 'edition *= *"[^"]\+"' . \
--exclude-dir=target | grep -v 'edition *= *"2024"'
```

## Older versions

If they use older versions we should

1.  Update the version and
2.  Fix any new warnings
3.  Verify with the usual checks
