# Documenting code.

We want to ensure our code has appropriate documentation.  

# Gathering information

Let's focus on new types that are more suspect.

```bash
cargo public-api -sss > new.txt
```

# Verifying documentation

Run the documentation check script to ensure all public items are documented: 
```bash
~/.claude/skills/release_prep/scripts/check_docs
```

Ensure that the 

* modules
* structs
* methods

have appropriate and up to date documentation.

# Missing documentation

If you identify documentation to be missing, add it.
