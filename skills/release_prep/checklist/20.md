# MSRV

First, find the rust version declarations we have already:

```bash
grep -R "rust-version =" . --include "*.toml" --exclude-dir=target
```

Temporarily remove them (delete the line).

Use the cargo msrv find command:

```bash
cargo msrv find
```

Re-add the version declarations you deleted, using the version detected by `cargo msrv find`

NOTE: If we detected the same version that was originally in the file, report NO edits
If we detect a DIFFERENT version than was in the file, report we MADE edits
