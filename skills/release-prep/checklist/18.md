# SPDX headers

Run the SPDX tool in check-only mode:

```bash
scripts/spdx
```

If it reports missing headers, apply them explicitly and re-run the check:

```bash
scripts/spdx --apply
scripts/spdx
```

Run it once at the repository root, including a virtual workspace root: it groups
files by the crate that owns them and takes each crate's identifier from its
`license`, from `[workspace.package]`, or from a header a sibling file already
has. If a crate states no license anywhere, the tool names it and exits 2; fix
the manifest, or pass `--spdx "MIT OR Apache-2.0"` to use one identifier
everywhere.
