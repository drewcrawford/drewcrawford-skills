# MSRV

First, find the rust version declarations we have already:

```bash
grep -R "rust-version =" . --include "*.toml" --exclude-dir=target
```

Temporarily remove them (delete the line).

Find the edition, which sets the floor for the search:

```bash
grep -R "^edition" . --include "*.toml" --exclude-dir=target
```

Map the highest edition in the workspace to its minimum Rust version:

| edition | `--min` |
| ------- | ------- |
| 2015    | 1.49    |
| 2018    | 1.49    |
| 2021    | 1.56    |
| 2024    | 1.85    |

Use the cargo msrv find command, passing that floor:

```bash
cargo msrv find --min <version>
```

`--min` is required.  Without it, `cargo msrv` bisects starting from 1.31, and
no toolchain older than 1.49 exists for aarch64-apple-darwin, so the search
aborts immediately.  That is also why the 2015 and 2018 rows say 1.49 rather
than the edition's true floor.

Re-add the version declarations you deleted, using the version detected by `cargo msrv find`

NOTE: If we detected the same version that was originally in the file, report NO edits
If we detect a DIFFERENT version than was in the file, report we MADE edits
