# Gathering information

Run the docs comparison script to digest recent documentation changes:

```bash
scripts/compare_docs.sh
```

The script compares through a temporary git worktree; it must not stash changes or switch the current checkout.

It defaults to the newest tag as its baseline. If the repository has no tags, or the crate did not exist at that tag, it says so and compares against an empty baseline, so every documented item is reported as new — that is the correct behavior for a first release, and the whole surface is then what lib.rs has to introduce. Do not substitute your own baseline; pass an explicit tag or commit only if the user asks for one.
