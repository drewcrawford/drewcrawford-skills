# Trait audit

## Identifying new types

We want to focus on new public types.

```bash
scripts/compare_api.sh
```

## Trait audit

For each of the types, we want to check if it ought to conform to any of these traits:

* Debug
* Clone
* Copy
* PartialEq and Eq
* Hash
* Default
* Display
* From/Into
* AsRef/AsMut
* Deref / DerefMut
* Error

## auto-trait audit

We also want to audit if it makes sense to guarantee these auto traits against future implementations:

* Send
* Sync
* !Unpin

## enum audit

Each public enum should be either
* marked as #[non_exhaustive]
* documented as to why

If you aren't confident about which one we need to do: abort this step and ask.
