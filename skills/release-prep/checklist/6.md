# Trait audit

## Identifying new types

We want to focus on new public types.

```bash
scripts/compare_api.sh
```

The script compares through a temporary git worktree; it must not stash changes or switch the current checkout.

It defaults to the newest tag as its baseline. If the repository has no tags, or the crate did not exist at that tag, it says so and compares against an empty baseline, so every public item is reported as new — that is the correct behavior for a first release, and the whole surface is then the audit list. Do not substitute your own baseline; pass an explicit tag or commit only if the user asks for one.

## Trait audit

For each of the types, we want to check if it ought to conform to any of these traits:

* Debug
* Clone
* Copy
* PartialEq and Eq
* Hash
* Default
* Display
* From/Into
* AsRef/AsMut
* Deref / DerefMut
* Error

## auto-trait audit

We also want to audit if it makes sense to guarantee these auto traits against future implementations:

* Send
* Sync
* !Unpin

## enum audit

Each public enum should be either
* marked as #[non_exhaustive]
* documented as to why

If you aren't confident about which one we need to do: abort this step and ask.
